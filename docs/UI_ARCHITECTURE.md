# EigenGraph Spatial UI Architecture Contract (North Star Specification)

To maintain consistent product direction across all future phases (`v0.4.8+`), EigenGraph enforces four strict UI/UX boundaries in **Spatial Mode**:

1. **100% Unified Earth 3D Viewport (No Separate `BIM 3D` or `Plan 2D` Modes in `v0.5.5+`)**:
   - All Spatial modeling (`Column`, `Beam`, `Wall`, `Footing`, `Slab`), vector drafting (`Line`, `Rect`, `Circle`, `Dimension`), geodesic measurement, structural lenses (`DCR%`, `ARI`, `Moment`, `4D`), and camera presets (`Iso`, `Top`, `Elev`) execute **directly on the single edge-to-edge 3D Earth Globe** (`SpatialCanvasMode::EarthGlobe`). Separate `BIM 3D` and `Plan 2D` canvas workspaces are removed in `v0.5.5`.
   - No permanent docked sidebars, side panels (`Panel::right` / `Panel::left`), multi-row fixed toolbars, bottom-right Earth tile watermarks (`v0.5.3`), auto-generated Vault demo/welcome files (`v0.5.5`), or top-left corner chrome (`antigravity_top_left_capsule` removed in `v0.5.0`) may clutter the interactive Earth 3D viewport.

2. **Single Hover-Expandable Floating Dynamic Island (`src/views/spatial_workspace.rs`)**:
   - **Single Unified Morphing Capsule (`v0.5.2–v0.5.8`)**: Resting controls (with direct `Orbit / Column / Beam / Wall / Footing / Slab / Door / Window / Line / Rect / Measure / Terraform` brushes), Hover Extension controls (4-tier clean deck: **World Portfolio & Structural Health HUD** (`World: N Bldgs`, `Crit • Fly`, `Unlocated • Place`, `Next Unloc`), **Core Quick Actions** (`Undo/Redo`, `Fit`, `Export`, `IFC4` georeferenced, `Audit .md`, `API Key`, `Settings`, `More Tools`), unified **Earth 3D Studio Bar** (`Iso / Top / Elev`, `Story / + Story / + Slab / Isolate / Anchor Here`, `Clean / DCR% / ARI / Moment / 4D`, `Ortho`, `Grid`, `Map: Sat+Vec/Pure Vector/...`, `Topo`, `-15° / +15°` heading rotation), and collapsible Extended CAD/Terraform tools), interactive **Earth Site Location** card, and drawers (`Vault` with unlimited lazy `.ifc` streaming, `Show: All / Unlocated / Critical / Located` triage pills, `[GPS / City / Pin / Stage]` badges & 1-click **`Place`** buttons, `@ Context` including `@World Portfolio`, `/ Slash` including `/portfolio`, `History`, `Chat`) all grow seamlessly upward inside **one continuous rounded glass frame** (never stacking into two separate boxes). Mobile/touch viewports expose a compact `Deck` toggle in Row 1 so touch users can expand/collapse the island cleanly without hover.
   - **Resting State**: Displays the sleek 3-row translucent bottom-center dock (`Vault / Switch Vault / + Add Context / Model / Planning-Fast / Chat / History`, `Draw: Orbit Column Beam Wall Footing Line Rect Measure Terraform`, and Prompt Composer) while keeping the rest of the canvas unobstructed.
   - **Manual Drawing, Precision Drafting & `Esc` Orbit Return (`SpatialManualTool`)**: Direct 1-click toggles for `Orbit`, `Column`, `Beam`, `Wall`, `Footing`, `Line`, `Rect`, `Measure`, and `Terraform`, with numeric `L / deg / W / H / R` drafting inputs in the Active Tool Pill and instant `Esc` fallback back to pointer `Orbit / Select`.
   - **Slash Command Palette (`/`)**: Full command access to views, structural lenses, and on-demand engineering sheets (also triggerable from Gemini responses via `[[OPEN_SHEET:...]]`).

3. **Click-to-Inspect Smart Element Pop-Up**:
   - Element properties (`ResizeColumn`, `ResizeRun`, `ResizeWall`, `ResizeFooting`), FEM stress/utilization (`DCR%`, `ARI`, `SVD`, `N-1`), 5D/6D metrics, and element-scoped `@Element` AI prompts appear exclusively in a compact translucent pop-up when an element or Earth coordinate is clicked.

4. **On-Demand Heavy Engineering Sheets & Engine Growth**:
   - Detailed multi-table engineering workspaces (`/vault`..`/report`) open strictly as transient translucent modal sheets (`Esc` to close), keeping `/classic` as an explicit opt-in fallback.
   - Future phases (such as live Gemini API execution, async FEM/ARI tool calling, Planning diff review cards, and Vault AI thread persistence) must execute **inside the Dynamic Island and Smart Pop-Up** without introducing new permanent panels or toolbars.
