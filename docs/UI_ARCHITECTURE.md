# EigenGraph Spatial UI Architecture Contract (North Star Specification)

To maintain consistent product direction across all releases (`v0.4.8+`), EigenGraph enforces four strict UI/UX boundaries in **Spatial Mode**:

1. **100% Unified Pure-Vector WebGL2 & IFCX (IFC 5) Living Earth 3D Viewport (Zero Raster Pixels; 100% Pure IFCX; Unified GPU BIM/FEM/City-Builder, District Multi-Hazard, Subsurface SSI Cutaway, Automated Retrofit, CRC Progressive Collapse & IFCX Visual Diffing in `v0.7.2`)**:
   - All Spatial modeling (`Column`, `Beam`, `Wall`, `Footing`, `Slab`, `Road`, `Bridge`, `Zone`, `Grade Pad`), vector drafting (`Line`, `Rect`, `Circle`, `Dimension`), geodesic measurement, structural lenses (`DCR%`, `ARI`, `Moment`, `Deform`, `Modal`, `4D`), interactive `N-1` single-member disruption overlays, automated structural retrofit strengthening (inclined 3D `BRB` braces, RC jacketing, shear wall infill, Before/After comparison, `Delta .ifcx` export), Two-Stage `ARI v2 + StructGNN-CRC` conformal screening & animated 3D domino progressive collapse cascade (`CRC .ifcx`), 3D subsurface borehole stratigraphy & groundwater table X-Ray cutaway coupled with 6-DOF Winkler foundation springs (`SSI .ifcx`), multi-layer IFCX visual diffing (`+Added / ~Modified / -Deleted` 3D ghosts, `Diff .ifcx`) & 100% pure-vector A3 SVG engineering dossier export, district multi-hazard layers (`Seismic Wave`, `Pounding`, `Venturi Wind`, `3D Flood`), pure-vector Earth themes (`Coastal Blueprint`, `City Daylight`, `Night Cyber-Twin`, `Topographic`), hardware WebGL2 Day/Dusk/Night lighting, and camera presets (`Iso`, `Top`, `Elev`) execute **directly on the single edge-to-edge 3D Pure-Rust WebGL2 Vector Earth Globe driven natively by `earth_globe.ifcx`** (`SpatialCanvasMode::EarthGlobe`). Separate `BIM 3D` and `Plan 2D` canvas workspaces are removed, all external raster/OSM tiles are retired, native WebGL2 (`egui_glow`) 24-bit Z-buffered rendering with `f64 → f32` RTC floating origin renders Earth, IFCX City-Builder infrastructure, subsurface stratigraphy, district multi-hazard overlays, and active 3D BIM/FEM/Modal/N-1/Retrofit/Cascade/Diff structures together in one unified GPU pass, and 100% pure-Rust composable IFCX (IFC 5 JSON ECS) replaces all legacy STEP `IFC2x3`/`IFC4`/`IFC4.3` parsers.
   - No permanent docked sidebars, side panels (`Panel::right` / `Panel::left`), multi-row fixed toolbars, bottom-right Earth tile watermarks, auto-generated Vault demo/welcome files, or top-left corner chrome may clutter the interactive Earth 3D viewport.

2. **Single Morphing & Dynamically Widening Floating Dynamic Island (`src/views/spatial_workspace/`, `SpatialIslandHost`)**:
   - **Single Unified Liquid Glass Capsule (ZERO Detached Pop-Ups in `v0.7.2`)**: Styled with the **Coastal Marine Teal Liquid Glass UI System** (`#0B1427`, `#2B4963`, `#5B92A5`, `#D0EBE1` via `MacTheme::{glass_capsule_frame, glass_subpill_frame, glass_chip_style, paint_glass_specular_sheen}`). Resting controls (balanced Left/Right Row 1 header, grouped Row 2 Quick-Draw sub-pill, **integrated Active Lens, N-1 Disruption, District Resilience, Automated Retrofit, CRC Cascade Stepper, Subsurface SSI + GWT Stepper, IFCX Diff Badge & Manual Tool Strip**, and frosted Coastal Teal Prompt Composer), Hover Extension Studio Deck (**4-Tab Segmented Studio Switcher** across `View & Lens` with `CRC & Cascade:` controls, `BIM & Story` with `Retrofit: Mode / Auto-Retrofit / + BRB / + Jacket / View: Before-After / Delta .ifcx`, `GIS & Site` with Vector Theme, `Sun: Day/Dusk/Night`, `GPU 3D`, IFCX Topo, **`IFCX City` Road/Bridge/Zone/Grade Pad/Road Snap**, **`Multi-Hazard:` Seismic/Pounding/Venturi/Flood 3D + `AI Scan -> IFCX`**, and **`SSI & Soil:` Winkler SSI / Soil Archetype / Liquefy / X-Ray Ground / `SSI .ifcx`** controls, plus `CAD & Export` with `Clone ↑`, `+ Footings`, `IFCX`, `Earth .ifcx`, and **`IFCX Diff & Dossier:` Snapshot Base / Visual Diff / Diff .ifcx / Vector Dossier .svg** export controls), interactive **Earth Site Location** card, and **Exclusive Drawers** (`Vault`, `@ Context`, `History`, `API Key`, `Multi-Layer IFCX Visual Diff Inspector`) all grow seamlessly upward inside **one continuous rounded glass frame** (never stacking into separate top/bottom boxes).
   - **Automatic Wide Expansion for Rich Panels**: When hosting Settings & About, the Smart Element Inspector, Multi-Layer IFCX Visual Diff Inspector, Vault Startup Setup, Unified Workspace Import, CAD Shortcuts/Quick-Jump (`Ctrl/Cmd+K`), or any of the 15 Engineering Module Sheets (`/vault`..`/report`), the single Dynamic Island smoothly widens up to `min(vp.x - 24 px, 1040 px)` on desktop (and fits strictly within `vp.x - 14 px` on phones/tablets with zero horizontal jump or overflow), keeping `hud_rects.len() == 1` at all times.
   - **Manual Drawing, Precision Drafting & `Esc` Orbit Return (`SpatialManualTool`)**: Direct 1-click toggles for `Orbit`, `Column`, `Beam`, `Wall`, `Footing`, `Line`, `Rect`, `Measure`, and `Terraform`, with numeric `L / deg / W / H / R` drafting inputs in the Active Tool Pill and instant `Esc` fallback closing any active Dynamic Island panel before returning to pointer `Orbit / Select`.
   - **Slash Command Palette (`/`)**: Full command access to views, IFCX City-Builder tools (`/road`, `/bridge`, `/zone`, `/gradepad`), district hazard & AI capture commands (`/seismic`, `/wind`, `/flood`, `/hazard`, `/ai-capture`), subsurface geotechnical SSI commands (`/ssi`, `/borehole`, `/liquefaction`, `/subsurface`, `/ssi-ifcx`), multi-layer IFCX diff & pure-vector dossier commands (`/snapshot`, `/diff`, `/diff-ifcx`, `/dossier`), automated structural retrofit commands (`/retrofit`, `/brb`, `/jacket`, `/retrofit-ifcx`, `/before-after`), Two-Stage `ARI v2 + StructGNN-CRC` cascade screening (`/cascade`, `/crc`, `/cascade-ifcx`), structural lenses, and embedded engineering module sheets (also triggerable from Gemini responses via `[[OPEN_SHEET:...]]`).

3. **Embedded Click-to-Inspect Smart Element Inspector (Inside Dynamic Island)**:
   - Element properties (`ResizeColumn`, `ResizeRun`, `ResizeWall`, `ResizeFooting`), live **2D Reinforced-Concrete Cross-Section & Rebar Cage Preview** with LRFD DCR% / ARI target progress gauges, FEM stress/utilization (`DCR%`, `ARI`, `SVD`, `N-1`), 5D/6D metrics, and element-scoped `@Element` AI prompts expand directly inside the unified Dynamic Island when an element or Earth coordinate is clicked (`Pin` keeps it anchored across clicks; `Esc` or `×` collapses cleanly).

4. **Embedded On-Demand Engineering Sheets & Settings (`Esc` to Close)**:
   - Workspace Settings & About, Vault Connection Setup, Unified Workspace Import, CAD Shortcuts/Quick-Jump, and all 15 detailed engineering workspaces (`/vault`..`/report`) open exclusively inside the widened Dynamic Island (`Esc` to close), keeping `/classic` as an explicit opt-in fallback.
   - All future capabilities (live Gemini API execution, async FEM/ARI tool calling, district multi-hazard controls, AI real-building `.ifcx` streaming, and Vault AI thread persistence) must execute **inside the single Unified Dynamic Island** without introducing detached pop-up windows or permanent sidebars.
