# EigenGraph Spatial UI Architecture Contract (North Star Specification)

To maintain consistent product direction across all future phases (`v0.4.8+`), EigenGraph enforces four strict UI/UX boundaries in **Spatial Mode**:

1. **100% Unified Pure-Vector Earth 3D Viewport (No Separate `BIM 3D` or `Plan 2D` Modes in `v0.5.5+`; Zero External Raster Tiles in `v0.6.4+`)**:
   - All Spatial modeling (`Column`, `Beam`, `Wall`, `Footing`, `Slab`), vector drafting (`Line`, `Rect`, `Circle`, `Dimension`), geodesic measurement, structural lenses (`DCR%`, `ARI`, `Moment`, `Deform`, `Modal`, `4D`), interactive `N-1` single-member disruption overlays, pure-vector Earth themes (`Coastal Blueprint`, `City Daylight`, `Night Cyber-Twin`, `Topographic`), and camera presets (`Iso`, `Top`, `Elev`) execute **directly on the single edge-to-edge 3D Pure-Rust Vector Earth Globe** (`SpatialCanvasMode::EarthGlobe`). Separate `BIM 3D` and `Plan 2D` canvas workspaces are removed in `v0.5.5`, and all external satellite/OSM raster tiles and Overpass APIs are retired in `v0.6.4`.
   - No permanent docked sidebars, side panels (`Panel::right` / `Panel::left`), multi-row fixed toolbars, bottom-right Earth tile watermarks (`v0.5.3`), auto-generated Vault demo/welcome files (`v0.5.5`), or top-left corner chrome (`antigravity_top_left_capsule` removed in `v0.5.0`) may clutter the interactive Earth 3D viewport.

2. **Single Hover-Expandable Floating Dynamic Island (`src/views/spatial_workspace.rs`)**:
   - **Single Unified Liquid Glass Morphing Capsule (`v0.5.2–v0.6.4`)**: Styled with the **Coastal Marine Teal Liquid Glass UI System** (`#0B1427`, `#2B4963`, `#5B92A5`, `#D0EBE1` via `MacTheme::{glass_capsule_frame, glass_subpill_frame, glass_chip_style, paint_glass_specular_sheen}` — higher-opacity frosted backdrop `alpha 222–228`, Coastal Teal rim, ambient drop shadow, and top refractive highlight). Resting controls (balanced Left/Right Row 1 header, grouped Row 2 Quick-Draw sub-pill using compact `SpatialManualTool::short_label()` brushes with category dividers, **integrated Active Lens, N-1 Disruption & Manual Tool Strip** with `4D Day`, `Deform` scale, `Modal M1–M3` Play/Pause, live `N-1 Restore` status, and `W/D/X/Y/L/∠` precision inputs, and frosted Coastal Teal Prompt Composer), Hover Extension Studio Deck (Telemetry + Utility Glass Pill Bar with `Pin` lock & `Alt+1..4` shortcuts, **4-Tab Segmented Studio Switcher** across `View & Lens`, `BIM & Story`, `GIS & Site` with Pure-Rust Vector Theme & IFC Topo controls, and `CAD & Export` with `Clone ↑` / `+ Footings`, grouped sub-pill capsules, and **Live Lens Colorbar Legend**), interactive **Earth Site Location** card, and **Exclusive Drawers** (`toggle_exclusive_drawer` across `Vault`, `@ Context`, `History`, and `API Key`, ensuring at most one drawer opens at a time) all grow seamlessly upward inside **one continuous rounded glass frame** (never stacking into separate top/bottom boxes). Mobile/touch viewports expose a compact `Deck` toggle in Row 1 so touch users can expand/collapse the island cleanly without hover.
   - **Resting State**: Displays the sleek 3-row translucent Liquid Glass bottom-center dock (`Vault / + Add Context / Model / Planning-Fast / History`, grouped `Quick-Draw` sub-pill, and frosted Prompt Composer) while keeping the rest of the canvas unobstructed.
   - **Manual Drawing, Precision Drafting & `Esc` Orbit Return (`SpatialManualTool`)**: Direct 1-click toggles for `Orbit`, `Column`, `Beam`, `Wall`, `Footing`, `Line`, `Rect`, `Measure`, and `Terraform`, with numeric `L / deg / W / H / R` drafting inputs in the Active Tool Pill and instant `Esc` fallback back to pointer `Orbit / Select`.
   - **Slash Command Palette (`/`)**: Full command access to views, structural lenses, and on-demand engineering sheets (also triggerable from Gemini responses via `[[OPEN_SHEET:...]]`).

3. **Click-to-Inspect Smart Element Pop-Up**:
   - Element properties (`ResizeColumn`, `ResizeRun`, `ResizeWall`, `ResizeFooting`), live **2D Reinforced-Concrete Cross-Section & Rebar Cage Preview** with LRFD DCR% / ARI target progress gauges, FEM stress/utilization (`DCR%`, `ARI`, `SVD`, `N-1`), 5D/6D metrics, and element-scoped `@Element` AI prompts appear exclusively in a compact translucent pop-up when an element or Earth coordinate is clicked.

4. **On-Demand Heavy Engineering Sheets & Engine Growth**:
   - Detailed multi-table engineering workspaces (`/vault`..`/report`) open strictly as transient translucent modal sheets (`Esc` to close), keeping `/classic` as an explicit opt-in fallback.
   - Future phases (such as live Gemini API execution, async FEM/ARI tool calling, Planning diff review cards, and Vault AI thread persistence) must execute **inside the Dynamic Island and Smart Pop-Up** without introducing new permanent panels or toolbars.
